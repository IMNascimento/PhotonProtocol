If it does not work

This page reports which stage gave up, not just that it failed. The two common outcomes have different fixes:

  • The code was not found in most frames — the screen is too small in the shot, too blurred, or too reflective. Get closer, hold steadier, and move the glare off it.
  • Not enough blocks — the recording was simply too short. Film the same transfer again for longer; the sender never repeats itself, so every extra second is new data.
