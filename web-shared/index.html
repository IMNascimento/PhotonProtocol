PhotonProtocol

Move a file from one device to another with nothing but a screen and a camera. No network, no cable, no pairing, no account, no server.

Send a file Receive a file

How to use it

  1. On the device that has the file, open “Send a file”, choose the file and start. The screen fills with a code that keeps changing.
  2. On the other device, open “Receive a file” and start the camera.
  3. Point the camera at the code and get close, until the code fills the width of the picture. An outline shows when it has been found.
  4. Hold it there. When the whole file has arrived it is offered by itself.

What this is

An open protocol for optical file transfer, and a reference implementation of it. Both pages run entirely on your device: nothing is uploaded, because there is nowhere to upload it to. After the first load they work offline.

The channel is one-way. The sender never learns whether anyone is watching, so it does not transmit the file once — it transmits an endless stream of fountain-coded fragments, and any sufficiently large subset rebuilds the whole. A picture lost to blur or glare costs time, never correctness.

Before you send anything sensitive

The channel is a screen in a room. Anyone who can see it can record it, and anyone who records it can decode it — that is the design, not a defect. You get integrity, not confidentiality. Encrypt anything private before handing it over.
