PhotonProtocol

Move a file from one device to another with nothing but a screen and a camera. No network, no cable, no pairing, no account, no server.

Sending

Open the sender on the device that has the file. It paints the file as a sequence of dense visual codes.

Turn the brightness up, turn off adaptive brightness and any night or warmth filter, and let it run full screen.

Receiving

Film that screen with the other device, using its ordinary camera app, at the highest resolution it offers. Then open the receiver and give it the recording.

Fill as much of the frame with the screen as you can, hold reasonably still, and keep recording for a few seconds longer than you think you need. Frames lost to blur or glare cost time, never correctness.

What this is

An open protocol for optical file transfer, and a reference implementation of it. Both pages run entirely on your device: nothing is uploaded, because there is nowhere to upload it to. After the first load they work offline.

The channel is one-way. The sender never learns whether anyone is watching, so it does not transmit the file once — it transmits an endless stream of fountain-coded fragments, and any sufficiently large subset rebuilds the whole. Film for as long as it takes.

Before you send anything sensitive

The channel is a screen in a room. Anyone who can see it can record it, and anyone who records it can decode it — that is the design, not a defect. PhotonProtocol gives you integrity, not confidentiality. Encrypt anything private before handing it over.
